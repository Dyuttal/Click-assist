# Click Assist (Geode mod)

## Build
1. Install the Geode SDK + CLI: https://docs.geode-sdk.org/getting-started/
2. `geode sdk install-binaries`
3. `geode build`  →  the `.geode` file is in `build/`, copy it to your Geode mods folder.

Or push this folder to GitHub — the included workflow builds for all platforms automatically.

Note: change `id`/`developer` in mod.json. Online leaderboards treat assist mods as cheats; keep "Practice mode only" on for legit runs.
